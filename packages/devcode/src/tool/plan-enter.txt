Switch to plan mode before a large or unclear task, then write a plan for the user to approve. Nothing changes until they approve it. The user sees that you switched.

Call this when:
- The task needs changes across several files, or a design decision
- The request is unclear enough that a wrong guess would waste work
- The user asks for a plan

Do NOT call this for questions, small fixes, tasks with an obvious answer, or when the user says to go ahead without planning.
