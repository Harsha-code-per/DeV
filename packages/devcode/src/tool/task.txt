Launch an agent that works on its own on a complex, multistep task. Set subagent_type to one of the agent types below.

Don't use it to read a known file, find a definition or search two or three files: Read, Glob and Grep are faster. If no agent type fits, use the other tools yourself.

Usage notes:
1. Launch several agents at once, in one message, when their work is independent. Don't redo work you delegated; do something else or wait.
2. The agent starts with no context unless you pass task_id to continue an earlier one. Give it a complete brief: the task, whether to write code or only research, how to check its work (such as the test command), and exactly what to report back.
3. Its single final message comes back to you, not to the user: tell the user what matters in a short summary. The result includes a task_id for continuing it later. Its results can generally be trusted.
4. If an agent type's description says to use it proactively, do so without being asked.
