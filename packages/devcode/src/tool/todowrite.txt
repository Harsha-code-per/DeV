Create and keep up a task list for this session: it organises multi-step work and shows the user your progress.

Use it when the work has 3 or more distinct steps, when the user gives several tasks or asks for a list, and when new instructions arrive (add them as todos). Skip it for a single simple task, a question, or one command. When in doubt, use it.

States: `pending`, `in_progress` (exactly one while work remains), `completed`, `cancelled`.

Rules:
- Mark a todo `in_progress` before starting it and `completed` as soon as it is done, including its verification; never on intent, and don't batch completions.
- If blocked or only partly done, keep it `in_progress` and add a todo describing the blocker.
- Keep items specific and actionable, and keep commands the user gave word for word.
