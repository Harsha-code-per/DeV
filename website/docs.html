DeV Code docs

DeV Code is a coding agent for your terminal. The commands dev and devcode do the same thing.

Install

On Linux or macOS:

curl -fsSL https://harsha-code-per.github.io/DeV/install | sh

On Windows, in PowerShell:

irm https://harsha-code-per.github.io/DeV/install.ps1 | iex

With npm, on any of them:

npm i -g devcode

The installers check the download against the release's SHA-256 checksums before installing anything. Update later with dev upgrade.

Connect a model

Start dev in a project folder and type /connect. Pick a provider, paste its key, and you're ready. DeV saves the key in its own private store, so you don't need env variables or a .env file.

If a provider's key is already in your shell, /connect offers to use it. It's never picked up silently.

Scripts and CI have nobody to answer that question, so dev run does read keys from the environment.

Free models

The default model is auto/free. For each request it tries the free models of the providers you've connected, moves to the next when one is busy, and remembers which ones answer well for you.

ProviderGood for
NVIDIAThe best starting point. Handles full coding tasks.
GoogleA large free tier, with a daily limit per model.
GroqVery fast, but limited to 8,000 tokens a minute, so it suits short tasks. DeV sends it a smaller request with fewer tools.
OpenRouterIts models with a :free suffix.
Ollama and LM StudioLocal models, found automatically.
FreeLLMAPIA separate app you run yourself. It combines many free tiers behind one key, for personal use. The capacity is large but not unlimited, and you add a key for each provider.

Free tiers have limits. When every model is rate limited, DeV waits if the limit clears soon, tells you what it's doing, and otherwise ends with a clear error. Connecting a second provider helps more than anything else.

Modes

DeV chooses how to work and shows you in the prompt. Press Shift+Tab to change it yourself.

ModeWhat happens
BuildThe default. DeV edits files, and asks before anything risky.
PlanFor larger or unclear work. DeV reads the code and writes a plan, and changes nothing until you approve it.
GoalFor "keep going until the tests pass". DeV checks the goal each time it stops, and a separate reviewer confirms it. Control it with /goal pause, /goal resume and /goal clear.
Accept editsFile edits are approved; everything else asks as usual.
AutoEverything that isn't denied is approved, including leaving the sandbox. Turn it on with --auto.

DeV decides from how you word the request, so unusual wording may just start in Build. You can switch at any time, or say "without planning" to skip a plan. Plan approval still asks you in Auto, because it is your decision and not a permission.

To run one prompt from a script:

dev run "explain this repo"
dev -p "fix the failing test" --output-format json

Configuration

Settings live in dev.json, either in your project or in ~/.config/dev/. Project memory lives in DEV.md. DeV also reads AGENTS.md and CLAUDE.md.

{
  "sandbox": {
    "network": { "allow": ["npm.mycompany.com"] },
    "filesystem": { "allowWrite": ["~/shared"], "allowRead": ["~/.npmrc"] }
  },
  "hooks": {}
}

Hooks use Claude Code's shape: PreToolUse, PostToolUse, UserPromptSubmit, Stop and SessionStart run as shell commands that get JSON on stdin. Exit code 2 blocks the action.

Security

DeV treats the model as untrusted, because text it reads can try to steer it.

  • On Linux and macOS, shell commands run in an OS sandbox. They can write only to your project, temp folders and package caches.
  • They can't read ~/.ssh, ~/.aws, other credential stores or DeV's key store.
  • Network access goes through an allowlist of package registries and git hosts.
  • Leaving the sandbox always asks you, unless you turned on Auto.
  • File edits and web fetches ask by default. Deny rules win in every mode.
  • Web pages and MCP results reach the model marked as untrusted.

Limits: Windows has no sandbox yet, PowerShell commands are never sandboxed, and local MCP servers run outside the sandbox. Read the full security policy.

Benchmarks

DeV Code passed 25 of 30 benchmark tasks on free models at no cost, with one run of each task. The tasks use hidden tests, and a do-nothing agent fails all of them.

On a sample of 5 of those tasks, Claude Code on Sonnet passed 5 and was faster, for $0.22. DeV Code passed 4 for free. A sample that small can't rank them. Codex hasn't been run yet. The tasks and results are in the bench folder.

FAQ

Is it really free?

DeV is free and open source, and free-tier models cost nothing. Each provider sets its own limits and has its own data terms, so check those for anything sensitive.

Can I use my Claude or ChatGPT subscription?

DeV can sign in to ChatGPT. For a Claude subscription, install Claude Code and DeV can hand a task to it, using your own login. DeV doesn't sign in to Claude Pro or Max itself, because Anthropic's terms don't allow that.

Does it send my code anywhere?

Only to the model provider you connect, or nowhere if you use a local model.

Why does it stop on a long task with Groq alone?

Groq's free tier allows 8,000 tokens a minute, and a long conversation needs more than that. Connect NVIDIA or Google with /connect.
